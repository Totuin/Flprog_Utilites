# Flprog_Utilites — базовые утилиты FLProg

Версия исходного эталона: **1.0.0**. Кандидат после ревизии: **1.0.1** (10.11.2026).

## Назначение

Библиотека предоставляет общие статусы/ошибки FLProg, задачи RT_HW, GPIO-обёртки, операции со временем и сетевыми адресами, преобразования чисел, а также адаптеры UART и определение объёма свободной памяти для различных архитектур.

## Области исходников

- `src/flprogUtilites.h/.cpp` — статусы, абстракции устройств, время, IPv4/MAC и конвертации.
- `src/rt_hwTask/` — классы задач, которые делегируют работу планировщикам RT_HW.
- `src/pin/` — цифровые и аналоговые пины, PWM/DAC.
- `src/flprogUart*` — аппаратный UART, программный UART (номер 100) и Bluetooth (номер 200).
- `src/variant/` — получение свободной памяти по архитектурам.

## Важные ограничения

1. `RT_HW_*` — внешние зависимости; их исходники не менялись.
2. В Arduino IDE необходимо установить совместимый комплект RT_HW (для соответствующего микроконтроллера).
3. В задачах режим `FLPROG_TASK_PERIODIK_SECONDS_EVENT_SKIP = 7`, `FLPROG_TASK_EXTERNAL_CHNGED_AND_PERIODIK_EVENT_SKIP = 9`. **Проверьте генератор FLProg, если он выдаёт числовой литерал вместо константы.** До этой ревизии оба имени имели значение 7.
4. `checkMacAddres()` сохраняет прежнюю специфичную для FLProg проверку: запрещены адреса из нулей и любой компонент `FF`.
5. Некоторые UART-вызовы сначала инициализируют неготовый порт и только следующим вызовом обрабатывают данные — исходное поведение сохранено.
6. `flprog::ipToNumber()` использует порядок байтов, совместимый с исходной реализацией на малопорядковых платформах (например, AVR/ESP): октет 0 — младший байт.

## Проверки

Автономные тесты на Linux/g++ с AddressSanitizer и UndefinedBehaviorSanitizer подтвердили работу изменённых операций времени, разбора MAC, преобразований IP/HEX/двоичной строки и переключения типов задач. Они не заменяют компиляцию библиотеки в Arduino с настоящими драйверами RT_HW и испытания на аппаратуре.

Проверка форматирования `keywords.txt`: 283 записи, дубликатов и ошибок табуляции не обнаружено.

Описание исправлений — в `CHANGELOG_FLPROG.md`; результаты аудита — в `AUDIT_FLPROG.md`.
